# Application Services Layer

## Overview
Implement the application services layer that orchestrates MessageProcessor components, manages RequestService lifecycle, and implements core business workflow logic.

## Acceptance Criteria
- [ ] MessageProcessor orchestrates RabbitMQ consumer and Claude API service integration
- [ ] RequestService lifecycle manages workflow request processing from start to completion
- [ ] Business workflow implementation handles different workflow types and states
- [ ] Service coordination ensures proper error handling and state management
- [ ] Workflow persistence tracks request status and results in database

## Technical Details

### Implementation Approach
- Create `WorkflowOrchestrator` that coordinates all services
- Implement `RequestProcessor` for handling individual workflow requests
- Use dependency injection for service composition
- Implement workflow state machine for request lifecycle
- Add comprehensive error handling and recovery mechanisms

### Key Components
```go
type WorkflowOrchestrator struct {
    consumer     *MessageConsumer
    claudeService *ClaudeService
    repository   *WorkflowRepository
    logger       *logrus.Logger
}

type RequestProcessor struct {
    orchestrator *WorkflowOrchestrator
    request      *WorkflowRequest
    context      *ProcessingContext
}

type WorkflowRequest struct {
    ID        string                 `json:"id"`
    Type      string                 `json:"type"`
    Status    string                 `json:"status"`
    Input     map[string]interface{} `json:"input"`
    Output    map[string]interface{} `json:"output,omitempty"`
    CreatedAt time.Time              `json:"created_at"`
    UpdatedAt time.Time              `json:"updated_at"`
}

type ProcessingContext struct {
    RequestID   string
    Conversation *ConversationContext
    Metadata    map[string]interface{}
    StartTime   time.Time
}
```

### Workflow State Machine
- **pending**: Request received, waiting for processing
- **processing**: Claude API interaction in progress
- **completed**: Workflow finished successfully
- **failed**: Error occurred, requires intervention
- **timeout**: Processing exceeded time limits
