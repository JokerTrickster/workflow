# Task: Domain Layer Implementation

## Description
Implement the core domain layer for the task queue system, including the Task entity with all its properties, repository interfaces for data persistence, domain validation rules, and status enumerations. This forms the foundation of the business logic layer.

## Acceptance Criteria
- [ ] Task entity implemented with all required fields (ID, name, script, status, timestamps, logs)
- [ ] Task status enum defined (pending, running, completed, failed, cancelled)
- [ ] Repository interface defined for task persistence operations
- [ ] Domain validation rules implemented for task creation and updates
- [ ] Value objects created for complex fields (TaskScript, TaskLogs)
- [ ] Domain errors defined for business rule violations

- Follow Go domain-driven design patterns
