# Task: Update Frontend Next.js Config and Environment Variables

## Description
Configure Next.js for static export and update environment variables to point to production backend, preparing frontend for S3 deployment.

## Acceptance Criteria
- [ ] `next.config.ts` updated with `output: 'export'` setting
- [ ] `next.config.ts` includes `images: { unoptimized: true }` (required for static export)
- [ ] `next.config.ts` includes `trailingSlash: true` for S3 compatibility
- [ ] `.env.production` file created with `NEXT_PUBLIC_API_BASE_URL=http://13.203.37.93:7000/api/v1`
- [ ] `NEXT_PUBLIC_GITHUB_TOKEN` removed from all environment files (security risk)
- [ ] `.env.example` updated with documentation
- [ ] `npm run build` successfully generates `out/` directory

## Technical Details
- **Files to Modify**:
  - `next.config.ts` - Add static export configuration
  - `.env.production` - Create with production backend URL
  - `.env.local` - Remove `NEXT_PUBLIC_GITHUB_TOKEN`
  - `.env.example` - Update documentation

- **next.config.ts Changes**:
  ```typescript
  import type { NextConfig } from "next";

  const nextConfig: NextConfig = {
    output: 'export', // Enable static HTML export
    images: {
      unoptimized: true, // Required for static export
    },
    trailingSlash: true, // S3 compatibility
  };

  export default nextConfig;
  ```

- **Environment Variables**:
  - Production: `NEXT_PUBLIC_API_BASE_URL=http://13.203.37.93:7000/api/v1`
  - Remove: `NEXT_PUBLIC_GITHUB_TOKEN` (use backend proxy instead)
  - Keep: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`
