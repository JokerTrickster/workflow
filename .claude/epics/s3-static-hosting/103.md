# Task: End-to-End Validation and Smoke Testing

## Description
Perform comprehensive end-to-end testing of the S3-deployed application to validate all features work correctly with direct backend calls and CORS configuration.

## Acceptance Criteria
- [ ] All smoke tests pass from S3-hosted application
- [ ] Zero CORS errors in browser console (DevTools check)
- [ ] Performance meets targets (FCP ≤1.5s, TTI ≤3s on 3G)
- [ ] Security validated (no PATs in bundle, grep verification)
- [ ] Rollback procedure tested and documented
- [ ] User (you) confirms application works as expected

## Technical Details
- **Smoke Tests to Perform**:
  1. **Task Operations**:
     - [ ] Create new task → verify backend creates it
     - [ ] View task list → verify tasks load from backend
     - [ ] Execute task → verify execution starts
     - [ ] Poll task status → verify status updates

  2. **Work Log Operations**:
     - [ ] Create work log entry → verify file created on backend
     - [ ] View work logs → verify logs load from backend
     - [ ] Verify daily log structure and timestamps

  3. **Epic Task Operations**:
     - [ ] Create epic task → verify markdown file created
     - [ ] View epic tasks → verify frontmatter parsed correctly
     - [ ] Update epic task → verify file updated
     - [ ] Delete epic task → verify file removed

  4. **GitHub Integration**:
     - [ ] Merge PR through backend proxy → verify GitHub API called
     - [ ] Check PR status → verify merge succeeded

  5. **Authentication**:
     - [ ] Login with Supabase OAuth → verify session persists
     - [ ] Reload page → verify authentication state maintained

- **CORS Validation**:
  - Open browser DevTools → Network tab
  - Verify all API calls show CORS headers:
    - `Access-Control-Allow-Origin: <s3-url>`
    - No preflight errors (OPTIONS requests succeed)
  - Console tab shows zero CORS errors

- **Security Validation**:
  ```bash
  # Verify no GitHub PAT in bundle
  grep -r "ghp_" out/

  # Verify no service role keys
  grep -r "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9" out/ | grep -v "anon"
  ```

- **Performance Testing**:
  - Chrome DevTools → Lighthouse
  - Run audit on 3G throttled connection
  - Verify FCP ≤1.5s, TTI ≤3s

- **Rollback Testing**:
  1. Backup current `out/` directory
  2. Delete S3 files: `aws s3 rm s3://workflow-s3-static/ --recursive`
  3. Upload backup: `aws s3 sync out-backup/ s3://workflow-s3-static/`
  4. Verify application restored
