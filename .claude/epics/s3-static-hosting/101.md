# Task: Delete API Routes and Update Frontend Services

## Description
Remove all 8 Next.js API routes and update frontend services to call backend directly, completing the migration to static export.

## Acceptance Criteria
- [ ] All 8 API route files deleted from `/src/app/api/` directory
- [ ] `WorkLogManager.ts` updated to call backend `/api/v1/work-logs` instead of `/api/work-logs`
- [ ] `githubApi.ts` updated with `mergeBackendPullRequest()` method
- [ ] No references to `/api/` routes remain in codebase (verified with grep)
- [ ] All services use `apiClient.baseURL` or `NEXT_PUBLIC_API_BASE_URL`
- [ ] Local testing passes with backend at `http://13.203.37.93:7000`

## Technical Details
- **API Routes to Delete** (8 files):
  1. `/src/app/api/v1/tasks/route.ts`
  2. `/src/app/api/v1/tasks/[id]/route.ts`
  3. `/src/app/api/v1/tasks/[id]/execute/route.ts`
  4. `/src/app/api/work-logs/route.ts`
  5. `/src/app/api/work-logs/entry/route.ts`
  6. `/src/app/api/work-logs/utils.ts`
  7. `/src/app/api/github/repos/[owner]/[repo]/pulls/[number]/merge/route.ts`
  8. `/src/app/api/epics/tasks/route.ts`
  9. `/src/app/api/epics/tasks/[id]/route.ts`

- **Service Updates**:
  - **WorkLogManager.ts**:
    ```typescript
    // Change from:
    const API_BASE = '/api/work-logs'

    // To:
    const API_BASE = `${process.env.NEXT_PUBLIC_API_BASE_URL}/work-logs`
    ```

  - **githubApi.ts**:
    ```typescript
    // Add new method:
    async mergeBackendPullRequest(owner: string, repo: string, pullNumber: number, options: MergeOptions) {
      const url = `${process.env.NEXT_PUBLIC_API_BASE_URL}/github/repos/${owner}/${repo}/pulls/${pullNumber}/merge`;
      return fetch(url, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(options),
      });
    }
    ```

- **Verification Commands**:
  ```bash
  # Verify no API routes remain
  grep -r "export async function GET\|POST\|PUT\|DELETE" src/app/api/

  # Verify no /api/ references in services
  grep -r '"/api/' src/services/

  # Verify services use apiClient
  grep -r "apiClient\|NEXT_PUBLIC_API_BASE_URL" src/services/
  ```
