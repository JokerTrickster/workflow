# Task: Deploy to S3 with Static Website Hosting

## Description
Create S3 bucket, configure static website hosting, upload static build, and update backend CORS to allow S3 origin.

## Acceptance Criteria
- [ ] S3 bucket created with static website hosting enabled
- [ ] Bucket policy configured for public read access
- [ ] Index document set to `index.html`
- [ ] Error document set to `404.html` (for client-side routing)
- [ ] Static build uploaded to S3 bucket root
- [ ] Backend CORS updated to whitelist S3 bucket URL
- [ ] Application accessible from S3 HTTP URL

## Technical Details
- **S3 Bucket Configuration**:
  - Bucket name: `workflow-s3-static` (or user's choice)
  - Region: Any (e.g., `ap-south-1`)
  - Static website hosting: Enabled
  - Index document: `index.html`
  - Error document: `404.html`

- **Bucket Policy** (Public Read):
  ```json
  {
    "Version": "2012-10-17",
    "Statement": [
      {
        "Sid": "PublicReadGetObject",
        "Effect": "Allow",
        "Principal": "*",
        "Action": "s3:GetObject",
        "Resource": "arn:aws:s3:::workflow-s3-static/*"
      }
    ]
  }
  ```

- **Deployment Commands**:
  ```bash
  # Build static export
  npm run build

  # Upload to S3 (AWS CLI)
  aws s3 sync out/ s3://workflow-s3-static/ --delete

  # Or use AWS Console to upload out/ directory
  ```

- **S3 Website URL Format**:
  - HTTP: `http://workflow-s3-static.s3-website-ap-south-1.amazonaws.com`
  - (No HTTPS - CloudFront not required per requirements)

- **Backend CORS Update**:
  - Update `CORS_ORIGIN` environment variable to S3 bucket URL
  - Restart backend to apply new CORS settings

## Dependencies

- [ ] AWS S3 account and credentials available
- [ ] AWS CLI installed (or use AWS Console)
