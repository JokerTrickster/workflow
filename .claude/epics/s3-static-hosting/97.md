# Task: Configure Backend CORS Middleware

## Description
Add CORS middleware to backend to allow cross-origin requests from S3 static website, supporting OPTIONS preflight requests.

## Acceptance Criteria
- [ ] CORS middleware added to backend application
- [ ] `Access-Control-Allow-Origin` set to S3 bucket URL (configurable via env)
- [ ] `Access-Control-Allow-Methods` includes GET, POST, PUT, DELETE, OPTIONS
- [ ] `Access-Control-Allow-Headers` includes Content-Type, Authorization, X-Requested-With
- [ ] `Access-Control-Allow-Credentials` set to true
- [ ] `Access-Control-Max-Age` set to 86400 (24 hours)
- [ ] OPTIONS preflight requests return 204 No Content
- [ ] Tested with curl OPTIONS request

## Technical Details
- **Implementation Location**: Backend middleware (e.g., `middleware/cors.go` or Express middleware)
- **Configuration**:
  ```go
  // Example for Go/Gin
  c.Writer.Header().Set("Access-Control-Allow-Origin", os.Getenv("CORS_ORIGIN"))
  c.Writer.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")
  c.Writer.Header().Set("Access-Control-Allow-Headers", "Content-Type, Authorization, X-Requested-With")
  c.Writer.Header().Set("Access-Control-Allow-Credentials", "true")
  c.Writer.Header().Set("Access-Control-Max-Age", "86400")

  if c.Request.Method == "OPTIONS" {
      c.AbortWithStatus(204)
      return
  }
  ```
- **Environment Variable**: `CORS_ORIGIN` (initially `http://13.203.37.93:4000` for testing, later S3 URL)
- **Preflight Handling**: Intercept OPTIONS requests and return 204 with CORS headers

## Dependencies
- [ ] Backend framework supports middleware (Gin, Express, etc.)
- [ ] CORS origin URL known (initially localhost, then S3 bucket URL)
