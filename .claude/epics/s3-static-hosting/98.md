# Task: Implement Backend Epic Tasks Endpoints

## Description
Implement GET/POST `/api/v1/epics/tasks` and GET/PUT/DELETE `/api/v1/epics/tasks/{id}` endpoints to handle epic task file operations with frontmatter parsing.

## Acceptance Criteria
- [ ] GET `/api/v1/epics/tasks` returns list of epic tasks with parsed frontmatter
- [ ] POST `/api/v1/epics/tasks` creates new epic task markdown file
- [ ] GET `/api/v1/epics/tasks/{id}` returns single task with frontmatter + content
- [ ] PUT `/api/v1/epics/tasks/{id}` updates task file (frontmatter and/or content)
- [ ] DELETE `/api/v1/epics/tasks/{id}` removes task file
- [ ] Frontmatter parsed using `gray-matter` library (or Go equivalent)
- [ ] Task metadata (status, priority, assignee) properly synchronized

## Technical Details
- **Implementation Location**: Backend `/api/v1/epics/tasks` routes
- **File Operations**:
  - Read/write `.claude/epics/repositories/{repo}/tasks/{id}.md`
  - Parse YAML frontmatter with task metadata
  - Preserve markdown content structure
- **Frontmatter Fields**:
  - `name`, `status`, `created`, `updated`, `github`, `depends_on`, `parallel`, `conflicts_with`
- **Library**: Use `gray-matter` (Node.js) or `gopkg.in/yaml.v3` (Go) for frontmatter parsing
- **Error Handling**:
  - 404 if task not found
  - 400 for invalid task data
  - 500 for file I/O or parsing errors

## Dependencies
- [ ] Backend has access to `.claude/epics` directory
- [ ] Frontmatter parsing library installed (`gray-matter` or Go YAML)
