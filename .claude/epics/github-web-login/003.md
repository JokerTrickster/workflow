# Task 003: Session Management - 인증 상태 관리 + 리다이렉션

## Overview

사용자의 인증 상태를 관리하고, 인증 여부에 따른 적절한 페이지 리다이렉션을 구현합니다. Supabase Auth 세션을 활용하여 전역 인증 상태 관리, 자동 토큰 갱신, 보호된 라우트 접근 제어를 처리합니다.

## Acceptance Criteria

- [ ] 전역 인증 상태 관리 (AuthProvider/Context)
- [ ] 자동 세션 복구 (페이지 새로고침 시)
- [ ] 토큰 만료 시 자동 재인증 또는 로그아웃
- [ ] 보호된 라우트 접근 제어 (Route Guard)
- [ ] 인증 상태별 자동 리다이렉션 로직
- [ ] 로그아웃 기능 구현
- [ ] 세션 상태 변화 감지 및 UI 업데이트

## Technical Requirements

### Authentication Context
- React Context로 전역 인증 상태 관리
- 사용자 정보 (User 객체) 저장
- 세션 정보 (Session 객체) 저장
- 인증 상태 (authenticated, loading, unauthenticated)

### Session Persistence
- Browser 새로고침 시 세션 자동 복구
- LocalStorage + Supabase 세션 동기화
- 세션 만료 전 자동 갱신 (Refresh Token 활용)

### Route Protection
- 인증 필요 페이지 보호 (HOC 또는 미들웨어)
- 미인증 사용자 자동 로그인 페이지 리다이렉션
- 인증된 사용자 로그인 페이지 접근 시 대시보드 리다이렉션

## Session Management Logic

### Session Lifecycle
1. **초기화**: 앱 시작 시 저장된 세션 확인
2. **활성화**: 로그인 성공 시 세션 저장 및 구독 시작
3. **갱신**: 토큰 만료 전 자동 갱신 (15분 전)
4. **무효화**: 로그아웃 시 세션 삭제 및 구독 해제

### Auto-Refresh Strategy
```tsx
const useTokenRefresh = () => {
  // 토큰 만료 시간 모니터링
  // 15분 전 자동 갱신 시작

}
```
