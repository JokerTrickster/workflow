# Task 002: Login UI - 로그인 페이지 + OAuth 플로우 구현

## Overview

사용자가 GitHub OAuth로 로그인할 수 있는 UI와 인증 플로우를 구현합니다. shadcn-ui 컴포넌트를 활용하여 깔끔한 로그인 페이지를 만들고, Supabase Auth와 연동하여 OAuth 인증을 처리합니다.

## Acceptance Criteria

- [ ] 로그인 페이지 컴포넌트 구현 (/login 라우트)
- [ ] GitHub 로그인 버튼 UI (shadcn-ui 활용)
- [ ] OAuth 인증 플로우 구현 (시작 → 콜백 → 세션 생성)
- [ ] 로딩 상태 표시 (인증 진행 중)
- [ ] 에러 상태 처리 (인증 실패, 네트워크 오류)
- [ ] 인증 성공 시 대시보드로 리다이렉션
- [ ] 반응형 디자인 (모바일/데스크톱 대응)

## Technical Requirements

### UI Components
- LoginPage: 메인 로그인 페이지
- GitHubLoginButton: OAuth 시작 버튼
- LoadingSpinner: 인증 진행 상태 표시
- ErrorMessage: 에러 메시지 표시 컴포넌트

### Authentication Flow
1. 사용자가 GitHub 로그인 버튼 클릭
2. Supabase Auth로 GitHub OAuth 시작
3. GitHub 인증 페이지로 리다이렉션
4. 사용자 승인 후 콜백 URL로 복귀
5. Supabase에서 세션 생성 및 토큰 저장
6. 대시보드 페이지로 자동 리다이렉션

### State Management
- 로딩 상태 (loading, idle, error)
- 에러 메시지 저장
- 리다이렉션 URL 관리

## Design Requirements

### Visual Design
- 중앙 정렬된 로그인 카드 (max-width: 400px)
- GitHub 브랜드 컬러 활용 (#24292e)
- shadcn-ui 디자인 토큰 준수
- 깔끔한 타이포그래피 및 간격

### Responsive Behavior
- 모바일: 카드 형태, 좌우 여백 16px
- 데스크톱: 중앙 정렬, 그림자 효과
- 버튼: 터치하기 적절한 크기 (44px 이상 높이)

### Loading States
- 버튼 클릭 시: 스피너 + "Connecting..." 텍스트
- OAuth 리다이렉션 중: 전체 페이지 로딩 오버레이
- 콜백 처리 중: 로딩 메시지 표시

## Error Handling

### Error Types
- 네트워크 연결 오류
