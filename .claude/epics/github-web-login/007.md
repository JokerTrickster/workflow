# Task: Responsive Design

## Description

모바일과 데스크톱 환경에서 최적화된 사용자 경험을 제공하기 위해 반응형 디자인을 구현합니다. TailwindCSS의 반응형 유틸리티를 활용하여 다양한 화면 크기에 맞는 레이아웃과 인터랙션을 구현합니다.

## Acceptance Criteria

### Desktop Layout (≥1024px)
- [ ] 레포지토리 카드를 3-4열 그리드로 표시
- [ ] 사이드바 네비게이션 표시 (향후 확장 대비)
- [ ] 검색/필터 바를 상단에 고정 배치
- [ ] 카드 호버 효과 및 shadow 적용

### Tablet Layout (768px - 1023px)
- [ ] 레포지토리 카드를 2열 그리드로 표시
- [ ] 네비게이션을 상단 헤더로 축소
- [ ] 검색 바의 적절한 여백 유지

### Mobile Layout (≤767px)
- [ ] 레포지토리 카드를 1열로 세로 배치
- [ ] 터치 친화적인 버튼 크기 (최소 44px)
- [ ] 햄버거 메뉴 또는 하단 탭 네비게이션
- [ ] 스와이프 제스처 지원 고려

### Cross-Platform Compatibility
- [ ] iOS Safari, Android Chrome 렌더링 검증
- [ ] 터치 스크린 및 마우스 입력 모두 지원
- [ ] 화면 회전 시 레이아웃 자동 조정
- [ ] 다크 모드/라이트 모드 지원 (CSS 변수 활용)

## Technical Requirements

### CSS Framework
- TailwindCSS 반응형 유틸리티 활용 (sm:, md:, lg:, xl:)
- CSS Grid와 Flexbox 조합으로 유연한 레이아웃
- Container queries 활용 검토 (지원 브라우저 한정)

### Component Updates
```typescript
// RepoCard 컴포넌트 반응형 개선
interface RepoCardProps {
  // ... 기존 props
  layout: 'grid' | 'list'; // 뷰 모드 전환 지원
}

// DashboardPage 레이아웃 조정
const DashboardPage = () => {
  const [viewMode, setViewMode] = useState<'grid' | 'list'>('grid');
  
  return (
    <div className="min-h-screen bg-background">
      <div className="container mx-auto px-4 sm:px-6 lg:px-8">
        {/* Responsive grid */}
        <div className={cn(
          "grid gap-4",
          viewMode === 'grid' 
            ? "grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4"
            : "grid-cols-1"
        )}>
          {repositories?.map(repo => (
            <RepoCard key={repo.id} {...repo} layout={viewMode} />
          ))}
        </div>
      </div>
    </div>
  );
};
```

### Performance Considerations
- 이미지 lazy loading (아바타, 언어 아이콘)
- Virtual scrolling (레포지토리 100개 이상 시)
- CSS 트랜지션 최적화 (transform, opacity 위주)

### Accessibility
- 키보드 네비게이션 지원
- 스크린 리더 호환성 (ARIA 라벨)
- Focus trap 구현 (모달, 드롭다운)
- 색상 대비비 WCAG 2.1 AA 준수

- Lighthouse 모바일 성능 점수 90+ 달성

## Testing Strategy

### Manual Testing
- 다양한 디바이스에서 실제 사용자 시나리오 테스트
- 화면 회전, 줌 인/아웃 시나리오
- 터치 제스처 및 키보드 네비게이션

### Automated Testing
```typescript
// 반응형 컴포넌트 테스트 예시
describe('DashboardPage Responsive', () => {
  it('displays grid layout on desktop', async () => {
    render(<DashboardPage />, { viewport: { width: 1024, height: 768 } });
    expect(screen.getByTestId('repo-grid')).toHaveClass('lg:grid-cols-3');
  });
  
  it('displays single column on mobile', async () => {
    render(<DashboardPage />, { viewport: { width: 375, height: 667 } });
    expect(screen.getByTestId('repo-grid')).toHaveClass('grid-cols-1');
  });
});
```
