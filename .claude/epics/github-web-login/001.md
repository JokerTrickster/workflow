# Task 001: Auth Setup - Supabase 프로젝트 + GitHub OAuth 설정

## Overview

GitHub OAuth 인증을 위한 기반 인프라를 구축합니다. Supabase 프로젝트 생성, GitHub OAuth Provider 설정, 환경 변수 구성을 포함하여 전체 인증 시스템의 기초를 마련합니다.

## Acceptance Criteria

- [ ] Supabase 프로젝트 생성 및 초기 설정 완료
- [ ] GitHub OAuth App 등록 (Client ID/Secret 발급)
- [ ] Supabase Auth에 GitHub Provider 연동 설정
- [ ] 환경 변수 파일 (.env.local) 구성
- [ ] Next.js 프로젝트에 Supabase 클라이언트 설정
- [ ] 기본 인증 설정 검증 (연결 테스트)

## Technical Requirements

### Supabase Setup
- 새 Supabase 프로젝트 생성
- Database URL 및 API Keys 확보
- Auth 설정에서 GitHub Provider 활성화
- Redirect URLs 설정 (개발/배포 환경)

### GitHub OAuth App
- GitHub 개발자 설정에서 OAuth App 생성
- Authorization callback URL: `{SUPABASE_URL}/auth/v1/callback`
- Application name: "Workflow GitHub Integration"
- Homepage URL: 로컬 개발 서버 URL

### Environment Configuration
```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# GitHub OAuth
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
```

### Next.js Integration
- @supabase/supabase-js 패키지 설치
- Supabase 클라이언트 초기화 파일 생성
- 기본 타입 정의 (User, Session 등)

## Implementation Details

### File Structure
```
lib/
  supabase/
    client.ts          # Supabase 클라이언트 초기화
    auth.ts           # 인증 헬퍼 함수들
types/
  auth.ts             # 인증 관련 타입 정의
```

### Key Functions
- `createSupabaseClient()`: 브라우저용 클라이언트
- `createSupabaseServerClient()`: 서버용 클라이언트  
- `getSession()`: 현재 세션 가져오기
- `signInWithGitHub()`: GitHub OAuth 로그인 시작
