# Task: Task History API Endpoint

## Description
Implement the REST API endpoint `GET /api/tasks/history/{repository_name}` with pagination support. The endpoint should return repository-specific task history sorted by creation date (newest first) with proper error handling and input validation.

## Acceptance Criteria
- [ ] Create GET endpoint `/api/tasks/history/{repository_name}`
- [ ] Support query parameters: `page` (default: 1), `limit` (default: 20, max: 100)
- [ ] Return tasks sorted by `created_at` DESC (newest first)
- [ ] Include pagination metadata in response
- [ ] Implement proper input validation for repository name and parameters
- [ ] Return appropriate HTTP status codes (200, 400, 404, 500)
- [ ] Follow exact JSON response format from PRD specification

## Technical Details
- **Files to modify**: Backend API router (Echo/Gin)
- **Response format**: JSON with `data` array and `pagination` object
- **Input validation**: Repository name format, page/limit ranges
- **Error handling**: Graceful error responses with proper status codes
- **Performance**: Target <200ms response time for typical queries
